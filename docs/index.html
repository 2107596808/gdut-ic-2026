项目经历

2048 游戏 + AI 自动求解

纯前端单文件 · HTML / CSS / JavaScript

阶段一是可以自己玩的完整 2048（键盘 / 鼠标拖拽 / 触屏都能操作，含计分制、主题切换、 最近 10 局战绩）；阶段二加入了 AI 自动演示：评估用角块启发式（把大块堆到角落）， 搜索用 expectimax，随机落子回合对每个空格按 90% 出 2 / 10% 出 4 做全宽期望， 深度随局面自适应。为了让搜索够快，整个棋盘被压成两个 32 位整数的位棋盘。

实测结果：固定 10 个种子各跑一整局（全程无人工）， 合出 1024 与 2048 的达成率都是 39/40 = 98%，其中 31 局合出 4096、4 局合出 8192；平均 2973 步、单次决策 1.1 ms。
