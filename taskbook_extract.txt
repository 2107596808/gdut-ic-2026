大一招新考核任务书
考核方式：个人独立完成，截止日期前提交，评审择优录取。
一、环境准备
1. 注册 GitHub 账号，创建一个个人仓库（后续全部作品提交到该仓库） 2. 安装 AI 编程工具
AI 编程工具与大模型不限品牌：国产（DeepSeek Harness、ZCode 等）、国外（Codex 等）皆 可，自主选择 3. 安装 Git 与代码编辑器（推荐 VS Code，免费）：后续提交作品、使用版本控制会用到
二、个人简介（PDF + 个人网站）
1. 个人简介 PDF：制作一份 PDF（姓名、专业、兴趣、联系方式等，内容自定），上传到自己的 GitHub 仓库
2. 个人网站：用 HTML/CSS 做一个个人主页，部署到 GitHub Pages（免费托管）。 网址格式： https://你 的 用 户 名 .github.io/仓 库 名 / 内容自定（自我介绍、兴趣、联系方式），样式自定。
三、通用素养
1. Git 操作：仓库中 git commit 不少于 3 次（证明是一步步做出来的）；在 README 中用一句话解释什 么是“分支”和“合并”。
2. 命令行：能说明 cd / ls / mkdir 和 git 常用命令的用途。 3. 信息与安全意识：
给项目加一个 LICENSE（如 MIT），并在 README 说明为什么选它； 开启 GitHub 两步验证； 在 README 中记录一条“AI 给过但我查证后认为是错误的信息”——查证的过程比结论更重要。 4. 防“纯粘贴”承诺：README 中，用你的话解释至少 2 处 AI 生成代码的关键逻辑（比如贪吃蛇为什么 能自动避开死路、2048 的评分函数是怎么想的）。
四、小游戏（三选一，分两阶段）
从以下三个游戏中任选一个制作，两个阶段都要完成： 1、贪吃蛇 2、2048 3、扫雷
